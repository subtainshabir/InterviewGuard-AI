# InterviewGuard AI

InterviewGuard AI is an AI-powered online interview integrity monitoring system. It's designed to evaluate multiple independent signals during a live interview — face, gaze, head pose, audio, object/person detection, and browser activity — and combine them into an explainable integrity risk score with a supporting evidence timeline, rather than treating any single behavior as proof of cheating.

**Stack:** FastAPI (Python) backend, React + Vite frontend, PostgreSQL + SQLAlchemy + Alembic for data.
