# InterviewGuard AI

InterviewGuard AI is an AI powered online interview integrity monitoring system. It evaluates multiple independent signals during a live interview, including face, gaze, head pose, audio, object and person detection, and browser activity. These signals combine into an explainable integrity risk score with a supporting evidence timeline, so no single behavior is treated as proof of cheating.

**Stack:** FastAPI (Python) backend, React + Vite frontend, PostgreSQL with SQLAlchemy and Alembic for data.
